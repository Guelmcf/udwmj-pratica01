# UDWMJ - Dev Web: Prática 01

Repositório destinado à Prática 01 da disciplina UDWMJ - Dev WEB, ministrada pelo Prof. Daniel Henrique Matos de Paiva.

## 📚 Sobre a Atividade
O objetivo desta prática é fixar os conceitos fundamentais de **HTML** e **CSS**, explorando a estrutura básica de páginas web e as três principais formas de aplicar estilos em uma página.

## 📝 Estrutura do Projeto
O repositório contém os seguintes passos propostos durante a aula:

* **Exercício 01 (`pratica01exercicio01.html`):** Estrutura básica de um documento HTML renderizando um título `<h1>` na tela.
* **Exercício 02 (`pratica01exercicio02.html`):** Aplicação de *Estilos em Linha* (CSS Inline) usando o atributo `style` diretamente na tag.
* **Exercício 03 (`pratica01exercicio03.html`):** Aplicação de *CSS Interno* usando a tag `<style>` no cabeçalho (`<head>`).
* **Exercício 04 (`pratica01exercicio04.html` e `pratica01exercicio04.css`):** Aplicação de *CSS Externo* com a folha de estilo vinculada via tag `<link>`.
* **Página Final:** Criação de uma página web com tema de preferência própria utilizando HTML e CSS Externo. A página atende aos seguintes requisitos:
  * Possui um título e três parágrafos.
  * O título e cada parágrafo possuem cores de fonte diferentes.
